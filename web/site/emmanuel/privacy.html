Privacy Policy

This policy covers Emmanuel Studio, which publishes videos to one YouTube channel, Emmanuel.

1. What we access

  • Google account authorisation. When the channel owner authorises this application, Google issues an access token and a refresh token for the scopes requested on the consent screen. Those scopes are limited to what publishing requires: reading basic channel information and uploading videos to the authorising channel.
  • The channel's own content metadata — the title, description and privacy status of videos this application has uploaded — so that an upload can be confirmed.
  • Nothing else. We do not read the owner's email, contacts, files, calendar, photos, or any other Google service, and we do not request scopes that would allow it.

2. What we store

  • The OAuth refresh token, encrypted at rest on a private server controlled by the channel owner. It is used only to upload videos to Emmanuel.
  • The video files, scripts, narration audio and a record of what was uploaded and when.
  • We do not store subscriber data, viewer data, or any personal data about third parties.

3. How we use it

Only to produce videos and publish them to Emmanuel. We do not sell, rent, trade or share this data with anyone, and we do not use it for advertising or profiling. Text sent to a language model to draft a script contains no personal data: it is a prompt describing the kind of story to write.

4. YouTube API Services

Emmanuel Studio uses YouTube API Services. By using this application, you are agreeing to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy, and use of the API is governed by the YouTube API Services Terms of Service.

5. Retention and deletion

  • Access can be revoked at any time at myaccount.google.com/permissions. Revoking it invalidates the stored token immediately; the application then stops uploading.
  • A request to delete stored data can be sent to agumoorewe@gmail.com. Stored tokens and records are deleted within 30 days of the request.
  • If a token has been unused, or authorisation has been withdrawn, it is deleted rather than kept.

6. Children

This application is not directed at children and has no end users other than the channel owner.

7. Changes

If this policy changes, the date at the foot of this page changes with it.
